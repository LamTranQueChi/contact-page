# To-Do List

## Description

This is a simple To-Do List web application built using HTML, CSS, and JavaScript.

Users can:

* Add new tasks to the list.
* Remove tasks by clicking on them.
* Manage a simple task list directly in the browser.

## Features

* Clean and simple user interface.
* Add tasks dynamically using JavaScript.
* Delete tasks with a single click.
* Responsive and lightweight design.

## Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation)

## How to Use

1. Open the `demo.html` file in a web browser.
2. Enter a task in the input field.
3. Click the **Add** button.
4. The task will appear in the list below.
5. Click any task to remove it from the list.
